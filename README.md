# Smart Loan & Finance Calculator 💰📊

## 📌 Overview
A robust, **purely client-side** web application designed to simulate and calculate loan installments, total profits, and generate detailed amortization schedules. The tool provides a comprehensive financial report, allowing users to accurately compare between **Islamic Finance (Fixed Murabaha)** and **Traditional Finance (Declining Compound Interest)** systems.

**Live Demo:** [Try the Calculator Here](https://nourenzi.github.io/loan-calculator/)

---

## ✨ Key Features
* **Dual Calculation Logic:** Dynamically calculates and compares exact monthly payments and total costs based on either Islamic Murabaha or Traditional declining interest rules.
* **Detailed Amortization Schedules:** Automatically generates comprehensive yearly and monthly breakdown tables showing the principal paid, profit/interest paid, and the exact remaining balance.
* **Smart Export & Sharing:** Built-in, print-optimized CSS for generating clean, official-looking PDF reports, alongside dynamic WhatsApp integration for instant result sharing.
* **Progressive Web App (PWA):** Fully installable on mobile (iOS/Android) and desktop devices, featuring a Service Worker for complete **Offline Mode** support.
* **Privacy Centric:** **100% Client-Side.** No sensitive financial data (loan amounts, rates, or durations) ever leaves the user's device or is sent to any server.
* **Responsive UI/UX:** A clean, mobile-friendly interface featuring a seamless Light/Dark mode toggle, floating action menus, and anti-inspect security measures.

---

## 🛠️ Tech Stack
* **HTML5:** Semantic structuring and SEO optimization.
* **CSS3:** Custom styling (CSS Variables, Grid/Flexbox), Dark Mode support, and Print Media Queries (No external CSS frameworks).
* **Vanilla JavaScript:** Core financial business logic, DOM manipulation, and dynamic table generation (Zero dependencies).
* **Service Workers & Web App Manifest:** For PWA capabilities and offline caching.
* **FontAwesome:** For intuitive UI/UX icons.
* **Google Tag Manager & Analytics:** Integrated for real-time traffic and user engagement tracking.

## ⚠️ Legal Disclaimer
This tool is strictly an **"Estimatory and Exploratory"** model. Results and amortization schedules are generated based on standard mathematical financial formulas. They are intended for preliminary evaluation and personal planning purposes only. Actual bank calculations may slightly differ due to specific institutional rounding policies, hidden processing fees, or life insurance additions.
