# حاسبة القروض والتمويل الذكية 💰

أداة سريعة ومجانية لمحاكاة شروط التمويل والقروض، تتيح للمستخدم المقارنة بدقة بين **نظام المرابحة الإسلامية (الثابتة)** و**نظام الفائدة التقليدية (المتناقصة)**.

## 🚀 المميزات (Features)
- **مقارنة الأنظمة:** حساب دقيق يوضح الفرق بين التمويل الإسلامي والتقليدي.
- **جداول سداد مفصلة:** توليد جداول سنوية وشهرية توضح (المسدد من الأصل، المسدد من الأرباح، والرصيد المتبقي).
- **الطباعة والتقارير:** إمكانية طباعة النتائج وحفظها بصيغة PDF بتنسيق نظيف.
- **تطبيق تقدمي (PWA):** إمكانية تثبيت الحاسبة على الهاتف الذكي والعمل بدون اتصال بالإنترنت (Offline Mode).
- **الوضع الليلي (Dark Mode):** واجهة مستخدم تدعم الوضعين النهاري والليلي.
- **حماية برمجية:** التطبيق يعمل بالكامل على المتصفح (Client-side) لضمان الخصوصية وسرعة الأداء.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **HTML5 & CSS3** (Vanilla)
- **JavaScript (ES6+)**
- **React 18** (عبر CDN للتفاعلية)
- **Tailwind CSS** (عبر CDN للتصميم المتجاوب)
- **Service Workers & Web App Manifest** (لدعم PWA)
